# Calculadora de Gorjeta

Calculadora para o terminal, feita em Python, que divide a conta de um restaurante entre várias pessoas, já com a gorjeta incluída.

## Como funciona

1. O usuário informa o valor total da conta em reais (use ponto como separador, ex.: `300.00`).
2. Escolhe a porcentagem de gorjeta (ex.: 10, 12 ou 15).
3. Informa quantas pessoas vão dividir.
4. O programa mostra quanto cada pessoa deve pagar, arredondado para 2 casas decimais.

## O que pratiquei

- Entrada do usuário e conversão com `float()` e `int()`
- Operações aritméticas e porcentagem
- Arredondamento com `round()`
- Saída formatada com f-strings

## Como executar

```bash
python calculadora.py
```
